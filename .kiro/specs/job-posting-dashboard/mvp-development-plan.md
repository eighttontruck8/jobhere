# MVP 개발 순서

각 단계는 구현 후 독립적으로 검증할 수 있는 최소 작업 단위다. 앞 단계가 통과해야 다음 단계로 진행한다.

- [x] 1. Next.js + TypeScript 프로젝트 생성 및 핵심 화면 경로 구성
  - 완료 조건: `/dashboard`, `/profile`, `/postings/add`, `/postings/review` 빌드 성공
- [x] 2. Vitest + fast-check 테스트 실행 환경 구성
  - 완료 조건: 예제 단위 테스트와 property test 통과
- [x] 3. Prisma + PostgreSQL 연결 설정 및 데이터 모델 정의
  - 완료 조건: Prisma 스키마 검증과 Client 생성 성공
- [x] 4. 공고·평가기준·프로필 도메인 타입 정의
  - 완료 조건: TypeScript 타입 검사 통과
- [x] 5. 마감일 포맷·제목 축약·정렬 순수 함수 구현
  - 완료 조건: 단위/property test 통과
- [x] 6. 자격 프로필 입력 검증 함수 구현
  - 완료 조건: 정상값·경계값·오류값 테스트 통과
- [x] 7. 적합도 및 합격 가능성 계산 함수 구현
  - 완료 조건: 충족·미충족·누락·산출 불가 테스트 통과
- [x] 8. 공기업 통합 비교표·직무 필터·20개 제한 로직 구현
  - 완료 조건: 필터·중복·한도 테스트 통과
- [ ] 9. 공고 저장·조회 서비스와 API 구현
  - 완료 조건: 최신순/마감순 조회 및 저장 API 테스트 통과
- [ ] 10. 프로필 저장·조회 및 적합도 API 구현
  - 완료 조건: singleton 프로필 왕복 및 적합도 API 테스트 통과
- [ ] 11. 대시보드 실제 데이터 UI 구현
  - 완료 조건: 카드·사기업 목록·공기업 비교표의 정상/빈/오류 상태 확인
- [ ] 12. 프로필 입력·수정 UI 구현
  - 완료 조건: 유효성 오류와 저장 성공 상태 확인
- [ ] 13. 링크 원문 추출기 구현
  - 완료 조건: 정상 URL과 접근 실패 테스트 통과
- [ ] 14. 이미지 검증 및 비전 입력 변환 구현
  - 완료 조건: JPEG/PNG·10MB 제한 테스트 통과
- [ ] 15. LLM 구조화 추출·직무 필터·50개 제한 구현
  - 완료 조건: 외부 API mock 기반 분석 엔진 테스트 통과
- [ ] 16. 공고 추가·검토·편집·저장 UI 구현
  - 완료 조건: 링크/이미지 입력부터 검토 저장까지 통합 테스트 통과
- [ ] 17. 전체 오류 처리·반응형 UI·MVP 회귀 검증
  - 완료 조건: lint, build, 전체 테스트 및 핵심 사용자 흐름 통과
